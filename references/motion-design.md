# Motion Design

Motion graphics should improve one or more of:

- comprehension
- emphasis
- navigation
- pacing
- emotional impact
- visual storytelling

Useful systems include:

- kinetic typography
- callouts
- diagrams
- timelines
- charts
- UI cards
- tracked labels
- masks
- morphing
- parallax
- camera movement
- particles

Avoid:

- random glitches
- unnecessary spins
- constant zooms
- effect overload
- decorative motion that competes with the message
