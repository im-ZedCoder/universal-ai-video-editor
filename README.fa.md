# 🎬 Universal AI Video Editor

**ایده‌ی ساده را به یک ویدیوی حرفه‌ای و آماده‌ی انتشار تبدیل کن.**

Universal AI Video Editor یک Skill عمومی و مستقل از موضوع است که به مدل هوش مصنوعی کمک می‌کند مانند یک تدوینگر، کارگردان، موشن‌دیزاینر، طراح صدا، نویسنده و طراح زیرنویس حرفه‌ای عمل کند.

کاربر می‌تواند فقط موضوع، ایده، سناریو یا فایل‌های خام را بدهد؛ سیستم باید تصمیم‌های تولید را تا حد امکان به‌صورت خودکار انجام دهد.

---

## ✨ ویژگی‌ها

- 🎬 تدوین خودکار و متناسب با موضوع
- 🎨 موشن گرافیک و Kinetic Typography
- 📝 زیرنویس خودکار و زمان‌بندی‌شده
- 🇮🇷 پشتیبانی از فارسی و RTL
- 🎙️ طراحی و مدیریت Voiceover
- 🎧 موسیقی، SFX و صدای محیط
- 🎥 انتخاب B-Roll و ساختار بصری
- 🧠 تشخیص خودکار نوع محتوا و مخاطب
- 📱 بهینه‌سازی برای Reels، TikTok و Shorts
- 📚 پشتیبانی از مستند، آموزشی، تبلیغاتی، گیمینگ، سفر، داستان و بسیاری موضوعات دیگر
- 🔎 تأکید بر بررسی اطلاعات و جلوگیری از جعل Fact

---

## 🧠 ایده‌ی اصلی

```text
ایده کاربر
   ↓
درک موضوع
   ↓
تشخیص نوع محتوا و مخاطب
   ↓
سناریو و Hook
   ↓
برنامه‌ریزی تصویر + صدا + موشن
   ↓
زیرنویس
   ↓
تدوین
   ↓
کنترل کیفیت
   ↓
ویدیوی نهایی
```

هدف این است که کاربر مجبور نباشد هر بار مشخص کند «چه فونتی»، «چه ترنزیشنی»، «چه افکتی» یا «چه انیمیشنی» استفاده شود؛ سیستم باید بر اساس موضوع و سبک، انتخاب حرفه‌ای انجام دهد.

---

## 🌍 مستقل از موضوع

این پروژه فقط برای هوش مصنوعی نیست. می‌توان از آن برای موضوعاتی مانند موارد زیر استفاده کرد:

| موضوع | رویکرد پیشنهادی |
|---|---|
| تاریخ | مستند / داستانی |
| علم | آموزشی / اکسپلینر |
| گیمینگ | سریع و داینامیک |
| سفر | سینمایی |
| غذا | Macro / حسی |
| کسب‌وکار | حرفه‌ای / توضیحی |
| ورزش | اکشن و پرانرژی |
| آموزش | Screen Recording / Callout |
| محصول | Showcase / تبلیغاتی |
| داستان ترسناک | سینمایی / تنش‌محور |
| اخبار | اطلاعات‌محور |
| پادکست | Talking Head / Multicam |

این‌ها Templateهای اجباری نیستند؛ Skill باید براساس موضوع تصمیم بگیرد.

## 🚀 استفاده

ساده‌ترین ورودی می‌تواند فقط این باشد:

```text
برای من یک ویدیو درباره تاریخچه اینترنت بساز.
```

یا:

```text
یک ویدیوی ۶۰ ثانیه‌ای درباره نحوه کارکرد تورم بساز.
```

و در صورت نیاز می‌توان کنترل‌های بیشتری داد:

```text
TOPIC:
How electric cars work

DURATION:
60 seconds

LANGUAGE:
Persian

STYLE:
Cinematic educational

PLATFORM:
Instagram Reels
```

تنظیمات صریح کاربر همیشه بر Defaults اولویت دارند.

## 📝 زیرنویس و فارسی

سیستم برای زیرنویس باید موارد زیر را مدیریت کند:

- Transcription
- Timing
- Segmentation
- Typography
- Animation
- Safe placement
- RTL / LTR

برای محتوای فارسی، در صورت نصب بودن **Doran Fanum** می‌توان از آن به‌عنوان فونت زیرنویس استفاده کرد و در غیر این صورت یک فونت خوانا و مناسب جایگزین شود.

## 🎞️ موشن گرافیک

موشن باید کاربردی باشد، نه صرفاً تزئینی. بسته به محتوا می‌تواند شامل موارد زیر باشد:

- Kinetic Typography
- Callout
- Diagram
- Timeline
- Chart
- UI Card
- Map
- Counter
- Animated Icons
- Tracked Labels
- Parallax
- Mask / Morph
