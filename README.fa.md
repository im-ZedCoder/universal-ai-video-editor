# 🎬 Universal AI Video Editor

**ایده‌ی ساده را به یک ویدیوی حرفه‌ای و آماده‌ی انتشار تبدیل کن.**

Universal AI Video Editor یک Skill عمومی و مستقل از موضوع است که به مدل هوش مصنوعی کمک می‌کند مانند یک تدوینگر، کارگردان، موشن‌دیزاینر، طراح صدا، نویسنده و طراح زیرنویس حرفه‌ای عمل کند.

کاربر می‌تواند فقط موضوع، ایده، سناریو یا فایل‌های خام را بدهد؛ سیستم باید تصمیم‌های تولید را تا حد امکان به‌صورت خودکار انجام دهد.

---

## ✨ ویژگی‌ها

- 🎬 تدوین خودکار و متناسب با موضوع
- 🎨 موشن گرافیک و Kinetic Typography
- 📝 زیرنویس خودکار و زمان‌بندی‌شده
- 🇮🇷 پشتیبانی از فارسی و RTL
- 🎙️ طراحی و مدیریت Voiceover
- 🎧 موسیقی، SFX و صدای محیط
- 🎥 انتخاب B-Roll و ساختار بصری
- 🧠 تشخیص خودکار نوع محتوا و مخاطب
- 📱 بهینه‌سازی برای Reels، TikTok و Shorts
- 📚 پشتیبانی از مستند، آموزشی، تبلیغاتی، گیمینگ، سفر، داستان و بسیاری موضوعات دیگر
- 🔎 تأکید بر بررسی اطلاعات و جلوگیری از جعل Fact

## 🧠 ایده‌ی اصلی

```text
ایده کاربر
   ↓
درک موضوع
   ↓
تشخیص نوع محتوا و مخاطب
   ↓
سناریو و Hook
   ↓
برنامه‌ریزی تصویر + صدا + موشن
   ↓
زیرنویس
   ↓
تدوین
   ↓
کنترل کیفیت
   ↓
ویدیوی نهایی
```

هدف این است که کاربر مجبور نباشد هر بار مشخص کند «چه فونتی»، «چه ترنزیشنی»، «چه افکتی» یا «چه انیمیشنی» استفاده شود؛ سیستم باید بر اساس موضوع و سبک، انتخاب حرفه‌ای انجام دهد.

## 🌍 مستقل از موضوع

این پروژه فقط برای هوش مصنوعی نیست. می‌توان از آن برای موضوعاتی مانند موارد زیر استفاده کرد:

| موضوع | رویکرد پیشنهادی |
|---|---|
| تاریخ | مستند / داستانی |
| علم | آموزشی / اکسپلینر |
| گیمینگ | سریع و داینامیک |
| سفر | سینمایی |
| غذا | Macro / حسی |
| کسب‌وکار | حرفه‌ای / توضیحی |
| ورزش | اکشن و پرانرژی |
| آموزش | Screen Recording / Callout |
| محصول | Showcase / تبلیغاتی |
| داستان ترسناک | سینمایی / تنش‌محور |
| اخبار | اطلاعات‌محور |
| پادکست | Talking Head / Multicam |

این‌ها Templateهای اجباری نیستند؛ Skill باید براساس موضوع تصمیم بگیرد.

## 🚀 استفاده

ساده‌ترین ورودی می‌تواند فقط این باشد:

```text
برای من یک ویدیو درباره تاریخچه اینترنت بساز.
```

یا:

```text
یک ویدیوی ۶۰ ثانیه‌ای درباره نحوه کارکرد تورم بساز.
```

و در صورت نیاز می‌توان کنترل‌های بیشتری داد:

```text
TOPIC:
How electric cars work

DURATION:
60 seconds

LANGUAGE:
Persian

STYLE:
Cinematic educational

PLATFORM:
Instagram Reels
```

تنظیمات صریح کاربر همیشه بر Defaults اولویت دارند.

## 🧩 قالب ثابت، رابط کاربری و انیمیشن

Skill از یک Design System قابل‌استفاده‌مجدد برای ویدیوهای یک پیج استفاده می‌کند؛ نه اینکه در هر صحنه ظاهر تازه‌ای بسازد. کامپوننت‌های طراحی‌شده از اصول رابط کاربری **الهام‌گرفته از iOS** پیروی می‌کنند: کارت‌های گوشه‌گرد، سلسله‌مراتب واضح، فاصله‌گذاری کافی، متریال ظریف و آیکون‌های هماهنگ.

- آیدی پیش‌فرض `XodeOMiD` در گوشه بالا سمت راست قرار می‌گیرد؛ کوچک، خوانا و با جایگاه ثابت، مگر اینکه کاربر چیز دیگری بخواهد.
- اندازه فونت‌ها از یک مقیاس مشخص پیروی می‌کند و هیچ متن یا المانی نباید از محدوده کارت یا Safe Area بیرون بزند.
- متن‌های بزرگ و بولد باید خوانا بمانند؛ از Glow، Bloom و گرادیان‌های بیش‌ازحد اشباع استفاده نشود.
- قبل از خروجی، تمام صحنه‌ها از نظر بیرون‌زدگی متن، برش، هم‌پوشانی، کنتراست و تداخل زیرنویس بررسی می‌شوند.
- انیمیشن‌ها باید نرم و هماهنگ باشند؛ از حرکت خطی ناگهانی، پرش‌های اغراق‌شده و حرکت‌های بی‌دلیل پرهیز شود.

## 🎙️ روند گویندگی با ElevenLabs

این Skill **فایل صوتی نهایی گویندگی را تولید نمی‌کند**. در عوض، متن آماده ElevenLabs را همراه با نشانه‌های مکث، راهنمای لحن و جدول زمان‌بندی جمله‌ها ارائه می‌دهد. اگر ElevenLabs نشانه‌های مکث را مستقیماً پشتیبانی نکند، نسخه تمیز متن به‌همراه جدول جداگانه مکث‌ها داده می‌شود. پس از اینکه کاربر فایل صوتی تولیدشده را ارائه کرد، تدوین و زیرنویس با موج صوتی و مکث‌های واقعی هماهنگ می‌شوند. تا قبل از دریافت فایل، جای گویندگی در پروژه به‌صورت Placeholder مشخص باقی می‌ماند.
