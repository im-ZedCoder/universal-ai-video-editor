# Contributing

Thanks for contributing to Universal AI Video Editor. ❤️

## What makes a good contribution?

A good contribution should make the skill:

- more universal
- more reliable
- easier to use
- more accurate
- more accessible
- better at adapting to different subjects
- better at producing professional editing decisions

## Avoid

Please avoid contributions that:

- hard-code one specific topic
- force one visual style on every video
- require users to manually configure basic editing decisions
- add decorative effects without a clear purpose
- introduce unsupported factual claims
- make the skill dependent on a single commercial product without a strong reason

## Pull requests

Before opening a pull request:

1. Explain what changed.
2. Explain why it improves the skill.
3. Add or update examples when appropriate.
4. Keep the main `SKILL.md` readable.
5. Avoid duplicated rules.
6. Check that existing behavior is not unnecessarily broken.

## Adding a new content mode

If adding a new mode, document:

- when it should be detected
- preferred pacing
- visual language
- audio strategy
- subtitle behavior
- motion design principles
- quality-control considerations

The mode should remain a guideline rather than an inflexible template.
