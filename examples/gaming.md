# Example: Gaming

## Input

```text
Create a 30-second Reel from this gameplay footage showing the best moments.
```

## Expected behavior

The skill should:

- inspect the footage
- find high-value gameplay moments
- remove dead time
- use dynamic cuts
- emphasize important actions
- use punch-ins or speed ramps when useful
- synchronize SFX with major events
- add readable subtitles if speech exists
- preserve gameplay clarity
