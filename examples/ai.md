# Example: AI / Technology

## Input

```text
Create a 45-second video explaining what a new AI model does.
```

## Expected behavior

The skill should:

1. Identify the topic as technology/AI.
2. Avoid assuming the audience is technical.
3. Create a curiosity-driven hook.
4. Explain the model in accessible language.
5. Visualize the concept rather than relying only on text.
6. Add appropriate motion graphics.
7. Generate synchronized subtitles.
8. Use a modern technology visual language.
9. Verify factual claims when current information matters.
10. End with a concise CTA when appropriate.
